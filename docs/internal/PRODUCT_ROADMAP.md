# 移动端任务路线

跨端里程碑权威计划仍见[电脑仓库专项计划](https://github.com/wuqiuwangtian/TravelFlow-AI/blob/main/docs/internal/MOBILE_CONTINUITY_PLAN.md)，本页只安排移动侧工作。仓库拆分不代表框架定型或P0结束；当前事实见[PROJECT_STATUS](PROJECT_STATUS.md)。

1. **P0进行中：独立工程和网络适配。** [框架与兼容性评审](ANDROID_FRAMEWORK_REVIEW.md)已形成评审稿；用户确认优先旧Android＋可更新WebView，旧内核继续评估，未选定正式框架／最低版本。API24／26＋Chrome119（32位x86与64位x86_64）、API30／35＋WebView124，API33＋官方WebView109，以及API36＋官方WebView133已有存储、HTTP／TLS、断网冷启动与凭据冷读原型证据，具体覆盖见PROJECT_STATUS；旧内核能力不足时明确提示且保护原数据。第三方原版组件已获授权并与官方同包签名核对；64位进程加载32位组件的失败单独保留。单台用户授权ARM64／API36真机已通过本地启动、触摸保存／重放、USB本地HTTP／TLS、公开虚构凭据及强停冷读，映射缺失时仍可本地保存；未切换手机网络或调用公网供应商。USB回环配置已有隔离模拟器与该真机证据，双配置构建和打包策略已验证；旧系统64位组合现已补齐两组；SYN停顿在API24／35专用模拟器通过，DNS挂起时无法及时取消且总时限不能保证线程退出，已明确记录；可选debug客户端在API35平台解析与API24受控UDP机制下已通过即时取消、6000ms终态及域名HTTPS身份校验，原客户端保持对照；旧系统已引入MiniDNS core报文兼容实验，补CNAME、A／AAAA解码、TCP回退及真实关闭；已在API24／35绑定当前网络并验证代理拒绝与恢复；本轮已补两组蜂窝虚拟网络断开／重建、旧请求与监听释放、新Network上的显式新请求及离线冷启动保存，未计作并存网络无缝切换；API35一次恢复首请求失败未定因，已补只读定向诊断及503保留负例，15次正常尝试未复现、原问题仍待证据；不继续无界重跑同一条件，复发时按阶段／解析码定位；已补共享请求绝对期限与有界服务器切片，主机26组及API24固定双DNS备用接手／域名HTTPS、API35平台回归通过；同IP不同端口实验不代表真实多DNS环境，A／AAAA仍顺序查询、无类型保底或部分成功；本轮已按固定源码形成平台／项目的维护责任与双栈、缓存、搜索域、代理／Private DNS边界，建议优先复用系统解析；用户已确认预设服务商＋高级自定义地址，优先完整域名／局域网地址及按目标隔离凭据、默认HTTPS；短名称／内网HTTP／自定义CA另评审，正式配置尚未实现。已补本包私有辅助进程承载系统解析的可选debug机制对照：API24挂起取消、总期限、绑定期间取消、意外退出、新请求与TLS身份通过，主进程／账本不变；正式地址配置与该解析路线均未升格为产品实现。下一项有界验证辅助工作在网络丢失时退出、解绑与新网络新请求，并收口Private DNS拒绝／恢复条件及正式维护路线，失败则回到评审，不无限扩自研解析器，收口正式凭据与框架／支持范围取舍；每组须核对实际提供方、进程ABI及有副作用路径，不能把环境故障、安装或功能检测当正式兼容。旧系统生产DNS／网络兼容、正式传输集成、真实供应商和正式凭据策略仍有缺口。按评审证据交用户确认框架与拟支持范围后再进入后续阶段；不缩窄开源目标，不把实验适配升格为正式产品接口。
2. **P1未开始：完整业务契约与可靠本地存储。** 与电脑端共同明确消费写入、日期、版本、设备身份、幂等、删除、冲突和附件；不能只靠当前汇总样例。覆盖全部现有目标能力，清单参考[电脑仓库接口能力矩阵](https://github.com/wuqiuwangtian/TravelFlow-AI/blob/main/docs/internal/MOBILE_CAPABILITIES.md)，不擅自删掉高级工程、规划或回顾。
3. **P2／P3未开始：独立移动业务与安全直连。** 与电脑端分别交付，按约定协议验证离线写入、在线独立服务、配对、增量、重传与并发冲突；无常驻服务器、不加入云存储。不能直接同步活跃SQLite文件，也不默认同步密钥。
4. **P4／P5未开始：手机体验与集成验收。** 用户评审交互，覆盖真机权限／省电／升级和完整电脑规划→手机使用→直连→电脑复核。性能调查按用户要求暂缓。最终验收不能仅靠模拟器或构建通过。
